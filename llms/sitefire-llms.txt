# Sitefire

> Sitefire is a Generative Engine Optimization (GEO) platform that helps companies improve their visibility in AI-generated answers.

## Book a Demo

You can book a product demo with Sitefire programmatically using our REST API.

### Step 1: Check available slots

```
curl "https://sitefire.ai/api/book-demo/slots?date=YYYY-MM-DD&timezone=America/New_York"
```

### Step 2: Book a slot

```
curl -X POST https://sitefire.ai/api/book-demo \
  -H "Content-Type: application/json" \
  -d '{"name": "Your Name", "email": "you@company.com", "time": "<slot from step 1>", "timezone": "America/New_York"}'
```

No API key required. The API is public.
